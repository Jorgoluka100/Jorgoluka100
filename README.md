- **[Reliable Event Pipeline](https://github.com/Jorgoluka100/uni_projects/tree/main/projects/reliable_event_pipeline)** — incremental ingestion, schema contracts, reject handling, late events, idempotent loading, SQL quality checks, audit metrics and automated tests.

## How I work

- start with data quality and the decision the work needs to support
- use validation designs that match the real prediction or reporting problem
- compare against meaningful baselines before adding complexity
- make uncertainty, failure modes and limitations explicit
- package important work with tests, reproducible runners and CI where useful
- translate technical outputs into decisions rather than stopping at a metric
